# Canonical Huawei Kunpeng platform repository

This repository contains scripts and documentation for the Huawei Kunpeng platform.

## Initial configuration

A specific initialization script that enables PPAs, installs a 4K/64K kernel or updates optimized software has been implemented.
Instructions for the script execution can be found [here](https://github.com/canonical/kunpeng/blob/main/server-configuration-script/readme.md).
